# Week 1 AWS Cloud Computing Project

## Objective
Learn AWS fundamentals, IAM, S3, and basic Git/GitHub workflow.

## Core AWS Services
- EC2 - virtual compute
- S3 - object storage
- RDS - managed relational database
- Lambda - serverless function execution

## Mini Project
1. Create an IAM user with appropriate permissions.
2. Create an S3 bucket.
3. Upload static files.
4. Configure and test access according to the assignment.

> Security note: Public S3 access can expose files to the internet. Use it only when required for the learning exercise and remove public access afterward.
